# TOMOSHA reference analysis

The attached references are inspiration, not source material. No logos, posters, copy, brand colors, or exact layouts are copied.

## Reference 1: cinematic integrated homepage

Use the shared media canvas, strong backdrop, readable left content zone, large CTA, and the natural transition from hero into content rails. Adapt it with TOMOSHA saffron accents and Uzbek-first copy. Do not copy the featured film identity or composition.

## Reference 2: modular sidebar and library UX

Use the clarity of secondary navigation, library separation, profile/settings grouping, and mobile dock. Apply the sidebar only to library, profile, settings, or admin contexts. Keep the public homepage cinematic rather than dashboard-like.

## Reference 3: premium streaming landing

Use full-width hero scale, short title hierarchy, category/provider tiles, pagination, and deliberate atmospheric depth. TOMOSHA replaces provider branding with local-first categories: Jonli TV, Filmlar, Seriallar, Multfilmlar, Sport, Bolalar, Yangiliklar.

## Reference 4: local OTT content-first layout

Use the large featured carousel, partial neighboring slides, readable navigation, and local content priority. Build an original TOMOSHA composition, not a clone of any telecom or OTT service.

## Reference 5: full-bleed cinematic backdrop

Use backdrop-led storytelling, strong overlay contrast, transparent header behavior, readable metadata, and search as a first-class action. Keep artwork original or legally usable and avoid copying any visible title or character.

## Consolidated TOMOSHA direction

The public product should feel like a premium local OTT service: content first, live TV immediately visible, one clear watch action, large media rails, consistent artwork, Uzbek Latin copy, and a quiet but confident dark surface system. The engineering constraint is equally important: retain the secure server-side playback contract and never place provider credentials or private stream URLs in frontend assets.
